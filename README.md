# Junisignal legal (static site)

Public Privacy Policy and Data Deletion pages for Meta App Review.

## Meta App Dashboard URLs

After GitHub Pages is enabled, use (replace `YOUR_USERNAME`):

- Privacy Policy: `https://YOUR_USERNAME.github.io/junisignal-legal/privacy/`
- User Data Deletion: `https://YOUR_USERNAME.github.io/junisignal-legal/data-deletion/`

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `junisignal-legal`.
2. Upload everything in this folder to the repo root (`index.html`, `privacy/`, `data-deletion/`, `assets/`).
3. In the repo: **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: `main` (or `master`), folder: `/ (root)`.
6. Save, wait a minute, then open the site URL.

## Before you submit to Meta

1. Replace `privacy@junisignal.com` in both pages with an email inbox you monitor.
2. Confirm both URLs open without login and return HTTP 200.
3. Optional: check the Privacy Policy URL in [Meta Sharing Debugger](https://developers.facebook.com/tools/debug/).
